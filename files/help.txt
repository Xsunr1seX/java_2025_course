Ниже представлен весь функционал библиотеки:
1.добавить книгу
- Добавляет книгу по вашим данным(название, автор, жанр и год).
При отсутствии данных о авторе поле "автор" будет "John Doe".
При отсутствии данных о жанре поле "жанр" будет "unknown".
При отсутствии данных о годе необходимо написать 0.

2.удалить книгу
- Удаляет книгу по названию книги, если она существует в библиотеке.

3.найти книгу
- находит книгу по названию и выводит информацию о существовании книги в библиотеке.

4.вывести список книг
- Выводит список книг в библиотеке со информацией о каждой книге

5.редактировать книгу
- Редактирует информацию о книге по вашему запросу - изменение жанра, названия, года и автора.

6.импортировать книги из books.txt
- Добавляет в библиотеку книги из файла books.txt.
ПРИМЕЧАНИЕ:вид информации о книге имеет определенный формат внесения в файл books.txt:
[name = "Название", author = "Автор", genre = "Жанр", year = 1999]

7.Помощь
- Выводит необходимую информацию о функциях библиотеки.

8. Сохранить и выйти
- Сохраняет все изменения, произведенные в данной сессии, включая редактирование книг, добавление книг, импорт книг и т.д.
